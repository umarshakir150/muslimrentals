## Findings

1. **[MEDIUM]** Leaflet's default control z-index (1000) exceeds every app modal's z-index (100-200), so opening Login/Sign Up while still on /map can visually show map zoom/attribution controls above the modal -- a plausible non-lifecycle explanation for the founder's item-1 report.
   - Evidence: globals.css has no override for .leaflet-top/.leaflet-bottom; AuthModal.tsx:90, PostListingModal.tsx:100/121, ListingDetail.tsx:62 all use z-[100]; DeleteListingDialog.tsx:41 uses z-[110]; toaster.tsx:12 uses z-[200]. Leaflet's own stylesheet sets .leaflet-top/.leaflet-bottom to z-index:1000.
   - Recommended action: Frontend: test Login/Sign Up-as-overlay-on-/map specifically; if reproduced, scope down Leaflet's control z-index via CSS rather than raising modal z-indices.
2. **[LOW]** Current marker color #0a5c42 has very high contrast (~8:1) against white text because it's quite dark, which can read as near-black rather than a clear 'green' at 44px marker size -- matching the founder's complaint even independent of any stale-build issue.
   - Evidence: globals.css:114 .rental-marker { background: #0a5c42; color: white; ... }
   - Recommended action: Brighten to Tailwind green-700 (#15803d, ~5:1 contrast, still AA-compliant) or similar vivid green; leave sizing/padding/clustering untouched.
3. **[INFO]** Escape-to-close is not an established app-wide modal convention (only the destructive DeleteListingDialog has it); PostListingModal never had it, and the fix for item 4 does not need to add it to be 'consistent.'
   - Evidence: AuthModal.tsx:85-99, ListingDetail.tsx:59-63 have backdrop-click-close only, no onKeyDown/Escape handler. DeleteListingDialog.tsx:43 is the sole Escape handler in the codebase.
   - Recommended action: Frontend: remove backdrop onClick on both PostListingModal variants; do not add a new Escape handler.
